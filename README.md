# Oons App

Fondations d'un projet [Next.js](https://nextjs.org) (App Router, TypeScript) prêtes à évoluer vers une PWA.

## Démarrer en local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Structure

- `src/app/` — pages et layout (App Router)
- `public/manifest.json` — manifeste PWA (nom, icônes, couleurs)
- `public/icons/` — icônes de l'application

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build de production
- `npm run start` — lance le build de production
- `npm run lint` — vérifie le code avec ESLint
